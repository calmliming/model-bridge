Model Bridge · 全套 HTML 界面设计

打开方式
双击 index.html，即可离线体验全部页面。也可打开各业务 HTML 入口。
请保留整个 html 文件夹及 assets 子目录。无需安装或构建。

主要入口
index.html          18 套首页落地页设计汇总（含实际页面缩略预览）
landing-01.html 至 landing-18.html  18 套独立首页落地页
overview.html       管理后台总览
landing.html        品牌首页
login.html          登录与注册演示
user-overview.html  用户中心
models.html         模型广场
docs.html           使用文档

使用提示
左上角可切换管理员与个人工作空间。
Ctrl / Command + K 可搜索并跳转到页面。
顶部太阳图标可切换深浅主题。
在系统设置 → 关于系统中，可以恢复初始演示数据。

第 13、14 套为可爱风首页，分别搭配毛绒小兔插画与水豚绘本插画。
插画资产及精确生成提示词见 assets/cute-illustrations.txt。
第 15 套为黑白线条风，第 16 套参考 Claude 官网的暖白、陶土色及衬线排版。
参考来源与插画生成提示词见 assets/line-editorial-notes.txt。
第 17、18 套采用正式站点青绿色 #14b8a6 及深蓝灰，分别为居中产品预览与分栏品牌叙事。
配色来源：web/tailwind.config.js；小字号文字和按钮使用同色系深青色以保证对比度。
每套底部可切换上一套、下一套或返回总览；导航、文档、模型与演示入口均可点击。
接入代码可切换 cURL / JavaScript / Python 并复制。移动端可展开导航菜单。
全部资源均为本地文件，不依赖外部字体或 CDN。旧版 index.html#页面 路由仍兼容。

交付范围
保留现有产品演示页面，新增 18 套完整首页落地页及设计汇总入口。
页面使用本地模拟数据，支持筛选、分页、编辑、复制和 CSV 导出。
表单、支付、邀请、登录和 API 请求均为本地演示，不连接真实业务系统。
演示数据存入当前浏览器；隐私模式或部分 file 协议浏览器可能不允许持久化。

可选本地预览
在项目根目录运行：
python3 -m http.server 8765 --bind 127.0.0.1 --directory html
然后打开 http://127.0.0.1:8765/
