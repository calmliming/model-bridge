Model Bridge · 全套 HTML 界面设计

打开方式
双击 index.html，即可离线体验全部页面。也可打开各业务 HTML 入口。
请保留整个 html 文件夹及 assets 子目录。无需安装或构建。

主要入口
index.html          管理后台总览
landing.html        品牌首页
login.html          登录与注册演示
user-overview.html  用户中心
models.html         模型广场
docs.html           使用文档

使用提示
左上角可切换管理员与个人工作空间。
Ctrl / Command + K 可搜索并跳转到页面。
顶部太阳图标可切换深浅主题。
在系统设置 → 关于系统中，可以恢复初始演示数据。

交付范围
21 个设计页面，23 个 HTML 入口（包括兼容入口）。
页面使用本地模拟数据，支持筛选、分页、编辑、复制和 CSV 导出。
表单、支付、邀请、登录和 API 请求均为本地演示，不连接真实业务系统。
演示数据存入当前浏览器；隐私模式或部分 file 协议浏览器可能不允许持久化。

可选本地预览
在项目根目录运行：
python3 -m http.server 8765 --bind 127.0.0.1 --directory html
然后打开 http://127.0.0.1:8765/
