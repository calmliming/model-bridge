# GPT Image 2.6 接入说明

版本：**0.3.1**。核对日期：2026 年 11 月 5 日，北京时间。

## 模型和入口

- `gpt-image-2.6-flare`：快速生成与迭代。
- `gpt-image-2.6-sunburst`：精细构图与编辑。
- 生成：`POST /api/openai/v1/images/generations`。
- 编辑：`POST /api/openai/v1/images/edits`。
- 标准 `/v1/images/*` 入口同样支持；多渠道 Key 建议使用上面的显式 OpenAI 入口。
- `/v1/models` 默认目录、定价种子、模型广场和 API 文档加入两款型号。实际开放范围由上游账号模型目录及 Key/分组权限共同决定。

沿用已有 OpenAI 图片开关、账号调度、尺寸分流、流量限制与分组计费策略。第三方平台图片渠道没有确认供应这两个型号，因此没有为其增加供应能力或按张售价。

## 请求与输出

`complexity` 支持 `low`、`medium`、`high`，省略时使用上游默认值 `high`；它与 `quality` 独立。PNG、JPEG 和 WebP 支持现有生成、编辑和流式协议。

新增格式只用于生成接口：

| 格式 | 约束 |
| --- | --- |
| SVG | `output_format=svg`，`n=1`；不支持流式、正数 `partial_images`、`output_compression`、`mask` 或 `prompt_rewriter`。 |
| GIF | `output_format=gif`；`frame_count` 2–16，默认 9；`frame_duration_ms` 20–2000，默认 200；不支持流式、正数 `partial_images`、`output_compression`、`mask` 或 `prompt_rewriter`。 |

官方指南目前写 GIF 帧数 2–64，而接口参考写 2–16；本版本使用两者共同支持的 2–16，并将帧时长限制在指南给出的范围内。更宽的预览参数待官方契约统一后再扩展。实际权限和总像素预算仍由上游判断。

编辑支持 `markup`：上传与首张原图同尺寸、含透明像素的 PNG，或使用 JSON 对象 `{ "image_url": "https://..." }` / PNG data URL。不得同时传 `mask` 或 `prompt_rewriter`。原图与标注文件均受单文件 50 MiB 和请求总量限制；PNG 内容、透明像素和方向校正后的尺寸一致性由上游校验。原生账号不支持跨接口的 `file_id` 引用。

`response_format=b64_json` 保留原始编码。`response_format=url` 在网关转换为正确类型的 data URL，包括 `image/svg+xml`、`image/gif`，不会重新压缩或下载图片。SVG 用 `<img>` 预览，不注入页面 HTML。

API 文档左侧新增 **GPT Image 2.6**，提供生成、编辑调试页，支持复杂度、GIF 帧参数和标注层上传。

## 计费

按上游报告的实际用量结算；不根据帧数、尺寸或复杂度猜测 Token 数。GIF 的一份完成动画计为一份输出。

| 用量 | USD / 百万 Token |
| --- | ---: |
| 文本输入 | 5 |
| 文本缓存读取 | 1.25 |
| 图片输入 | 8 |
| 图片缓存读取 | 2 |
| 图片输出 | 30 |

两款型号有独立精确价格种子，避免继承旧图片模型的泛化配置；已有精确人工覆盖继续优先。

SVG 还可能返回 `svg_usage`。网关按其中作者模型的 `input_tokens`、`output_tokens` 单独计费，`reasoning_tokens` 作为输出的子集不会重复相加。用量和当时价格保存在账单 `billing_price.svg`；持久化重放保留原价格和总额。显式 `svg.model` / `svg.reasoning.effort` 原样用于作者选择，需要相应上游权限。

已报告用量的失败不会自动换号重放。分组配置按张替代 Token 计费时，SVG 作者 Token 也由该按张价格覆盖。
