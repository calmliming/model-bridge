# Model Bridge 界面重设计交付说明

本次交付在仓库根目录的 `html/` 文件夹中，覆盖现有管理后台、用户中心、公开页面与开发文档。入口为 `html/index.html`，无需安装依赖、构建或连接后端。

## 打开方式

直接双击 `html/index.html`。其他业务 HTML 文件也可直接打开，它们会进入统一入口的对应页面。各页面共用同一文档中的路由，以便离线导航时保留操作状态。

请完整保留 `html/` 和其中的 `assets/` 文件夹。字体使用系统字体，图标、模型目录与 ECharts 均已包含在交付目录中，页面运行不依赖 CDN。

需要本地 HTTP 预览时，在仓库根目录执行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory html
```

随后访问 `http://127.0.0.1:8765/`。

## 可体验的交互

- 左上角切换管理工作空间与个人工作空间；Ctrl / Command + K 搜索页面。
- 明暗主题切换、移动端侧边导航、键盘操作、弹窗关闭和焦点恢复。
- 总览周期切换、请求详情、用量趋势和服务商占比。
- 表格搜索、多条件筛选、分页、空状态和 CSV 导出。
- 账户创建、编辑、导入、模拟健康检查、停用及删除。
- 账户分组创建、编辑、成员分配、倍率设置和删除。
- 密钥创建、复制、编辑、停用及删除，支持额度、限速、并发和模型映射配置。
- 模型广场包含仓库目录中的 36 个模型，支持服务商、能力和关键词筛选及详情查看。
- 用户邀请演示、余额调整、充值订单模拟入账或取消。
- 兑换码生成与单次兑换，套餐编辑与上下架，用户钱包模拟充值与购买订阅。
- 文档分类和语言示例切换，API 请求 JSON 校验与本地响应示例。
- 常规、注册、调度、安全设置的本地保存；管理员密码表单校验。

## 数据与交付边界

所有账户、请求、费用、余额、密钥、充值、登录、邀请和 API 响应均为演示。演示不会向真实业务后端发送请求，不会执行真实付款、发送邮件或保存输入的密码。模型参数和价格来自仓库静态目录的示例快照，不代表在线报价。

交互数据使用 `model-bridge-html-v1` 本地存储键。可以在「系统设置 → 关于系统」恢复初始数据。浏览器禁用本地存储时，当前页面仍可操作，但关闭后可能不保留变更；HTTP 预览可避免部分浏览器对本地文件存储的限制。

本次添加 HTML 设计交付文件，原有 `web/` Vue 应用、后端、依赖清单和锁文件未修改。将此设计接入真实业务需再把页面结构、视觉样式与交互迁移到正式应用。

## 文件组织

- `html/assets/styles.css`：主题、组件和响应式样式。
- `html/assets/app.js`：页面、路由、演示数据和交互。
- `html/assets/icons.js`：导航图标。
- `html/assets/catalog.js`：模型目录快照。
- `html/assets/vendor/echarts.min.js`：本地图表库，许可证一并保留。
- `html/使用说明.txt`：离线打开与操作说明。
