# Image 2.5 原生接入与计费说明

日期：2026-09-13。版本：model-bridge `0.2.1`。

## 已接入模型与入口

支持以下模型，通过现有 OpenAI OAuth 账号调用 Codex 原生 Images 接口：

- `gpt-image-2.5-flare`
- `gpt-image-2.5-sunburst`
- `gpt-image-2.5-flare-2026-09-08`
- `gpt-image-2.5-sunburst-2026-09-08`

| 功能 | 本地接口 | 上游接口 |
| --- | --- | --- |
| 图片生成 | `/v1/images/generations` | `https://chatgpt.com/backend-api/codex/images/generations` |
| 图片编辑 | `/v1/images/edits` | `https://chatgpt.com/backend-api/codex/images/edits` |

本地接口也支持 `/api/openai/v1/images/` 前缀。模型映射后的目标为以上模型时进入原生路径，仍执行原有 Key/分组权限、账号调度、额度和计费规则。出站只发送图片参数，携带现有 OAuth 身份及可用的账号 ID，不构造文本主控模型或 `image_generation` 工具请求。原生接口调用方式参考 [Sub2API 实现](https://github.com/Wei-Shaw/sub2api/blob/bdb42e22f81fcb633ff0a060961211dd2bcb515b/backend/internal/service/openai_images_direct.go)。

省略 `model` 时仍默认 `gpt-image-2`，旧模型继续使用既有转发路径。Image 2.5 原生调用资格取决于上游账号，本次没有新增 API Key 类型的 OpenAI 账号。

## 参数与响应

Image 2.5 支持 `low`、`medium`、`high`、`xhigh`、`max`、`auto` 品质。透明背景须使用 PNG 或 WebP；JPEG 与透明背景组合在本地返回 400。尺寸支持 `auto` 或 `宽x高`，边长须为 16 的倍数、最长边不超过 3840、长宽比不超过 3:1、像素总数在 655360–8294400 之间。参见 [OpenAI 图片生成指南](https://developers.openai.com/api/docs/guides/image-generation)。

编辑支持 JSON 图片 URL/Data URL 与 multipart 文件/遮罩。沿用每个上传文件 20 MB、整个请求体 64 MB 的本地限制；原生路径不接受 `file_id`。JSON 提示词保留首尾空白，出站不发送内部字段或任意客户端附加字段。

JSON 返回标准图片结果；`response_format=url` 将 base64 转为 Data URL，不从远程地址下载图片。流式路径保留 `image_generation.*` / `image_edit.*` 的部分图和完成事件。请求流式但上游返回 JSON 时，会转换为对应的图片 SSE 事件。事件结构参考 [OpenAI Images API](https://developers.openai.com/api/reference/resources/images)。

没有最终图片的流返回明确错误；部分图不作为最终图片计数，重复完成帧不会重复计数。响应中已报告的用量会保留。失败已经产生图片或用量时不再自动重放，以免丢掉前次计费信息并重复生成；无用量的空结果仍可按现有策略换号。原生请求等待响应头的上限为 5 分钟，客户端取消仍会终止请求。

## 独立价卡与缓存计费

Flare、Sunburst 及对应日期快照使用独立价卡，不再被旧 Image 2 的数据库模糊匹配覆盖。当前两款模型官方单价相同，单位为美元/百万 token：

| 类型 | 单价 |
| --- | ---: |
| 文本输入 | 5 |
| 文本缓存输入 | 1.25 |
| 图片输入 | 8 |
| 图片缓存输入 | 2 |
| 图片输出 | 30 |

来源：[Flare 官方模型价卡](https://developers.openai.com/api/docs/models/gpt-image-2.5-flare)、[Sunburst 官方模型价卡](https://developers.openai.com/api/docs/models/gpt-image-2.5-sunburst)。原生图片端点的 `output_tokens` 按图片输出计费；不据质量和尺寸猜测 token 数，计费使用上游报告的实际用量。

图片缓存只采信明确的 `input_tokens_details.cached_tokens_details.image_tokens`，与文本缓存、未缓存文本、未缓存图片分为互斥计费桶。统计、用户用量、后台费用明细与钱包结算都计入新增字段；历史价格快照保留结算时的图片缓存单价，后续调价不改变已保存账单。

管理员可以在已有价格覆盖文件中为 `gpt-image-2.5-*` 配置 `imageCacheRead`，并配置其他单价。例如：

```json
{
  "version": 1,
  "rules": [{
    "provider": "openai",
    "model": "gpt-image-2.5-*",
    "price": { "input": 5, "output": 0, "cacheWrite": 0, "cacheRead": 1.25,
      "imageInput": 8, "imageCacheRead": 2, "imageOutput": 30 }
  }]
}
```

## 界面与升级

模型广场增加“图像生成”分类及两款模型的独立价卡。API 在线调试新增品质、背景和图片编码选项，生成默认选择 Flare，编辑默认选择 Sunburst。后台与用户用量明细补充图片 token；后台费用明细单列图片输入、输出及缓存费用。

新增 `usage_logs.image_cache_read_tokens` 与 `model_pricing.image_cache_read_price`。启动初始化和 [0013 迁移](../src/db/migrations/0013_image25_native.sql) 均为幂等加列，Drizzle 快照及 journal 已同步。部署包含本次修改的后端时自动补列；前端需重新构建。旧记录新增 token 列为 0，不回算历史费用；新增模型播种不覆盖管理员已有定价。

- 使用本地模拟 API 检查模型价卡、图片调试表单、`max + transparent + png` 实际提交参数与响应展示；检查了桌面和 390px 窄屏布局。
